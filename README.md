📊 إدارة المهام باستخدام Jira

تم استخدام Jira لتنظيم العمل ومتابعة تقدم المهام بين أعضاء الفريق بطريقة منظمة.

في البداية تم إنشاء مشروع خاص بالمادة على Jira، ثم تمت إضافة أعضاء الفريق إلى المشروع وتوزيع الأدوار بينهم.

بعد ذلك تم إنشاء Sprint لتجميع المهام الخاصة بمرحلة التنفيذ، وتم تقسيم العمل إلى مهام واضحة داخل الـ Sprint.

تم تتبع حالة كل مهمة عبر لوحة العمل (Board) باستخدام المراحل التالية:

To Do: المهام التي لم يبدأ تنفيذها بعد.

In Progress: المهام التي يتم العمل عليها حالياً.

Done: المهام التي تم الانتهاء منها بشكل كامل.

تم نقل المهام تدريجياً بين هذه الحالات حسب تقدم العمل، مما ساعد في تنظيم سير المشروع ومتابعة الإنجاز بشكل واضح.

بعد الانتهاء من تنفيذ المهام داخل الـ Sprint، تم إغلاقه باستخدام خيار Complete Sprint، حيث يتم حفظ جميع المهام المنجزة ضمن السبرنت المنتهي.

📸 تم توثيق مراحل انتقال المهام بين الحالات المختلفة بالإضافة إلى صورة توضح إغلاق الـ Sprint.
