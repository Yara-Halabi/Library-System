# Library-System
# 📚 Simple Library System

## 🎯 فكرة المشروع

نظام مكتبة بسيط يسمح للمستخدم بـ:

* إضافة كتاب جديد
* عرض جميع الكتب الموجودة في المكتبة
* البحث عن كتاب بالعنوان

هذا المشروع يهدف إلى تطبيق أساسيات إدارة المشاريع البرمجية باستخدام Git، GitHub، وJira، بالإضافة إلى العمل الجماعي المنظم.

---

## 👩‍💻 أعضاء الفريق وأدوارهم

* **يارا**: قائدة الفريق + إدارة GitHub + تنظيم الـ README
* **نوال**: تصميم وإنشاء قاعدة البيانات
* **مريم**: تصميم واجهة المستخدم البرمجية
* **إيمان**: التوثيق + إدارة Jira + توثيق مراحل العمل

---

## 🛠️ التقنيات المستخدمة

* Python
* SQLite
* Git & GitHub
* Jira

---

## ▶️ طريقة تشغيل المشروع

1. تحميل المشروع من GitHub
2. فتح المشروع باستخدام VS Code
3. تشغيل الملف الرئيسي الخاص بالواجهة
4. استخدام الأزرار لإضافة وعرض والبحث عن الكتب

---

## 📋 آلية العمل باستخدام Git

* لكل عضو فرع (Branch) خاص به.
* يتم رفع التعديلات عبر Commit.
* يتم دمج العمل إلى الفرع الرئيسي (main) باستخدام Pull Request.
